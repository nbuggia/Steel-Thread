## Hashbang

This project uses the Hashbang Agent Framework for persistent project memory and task management.

At the start of every session, before responding, read `.hashbang/framework/hashbang.md` in full and follow it. It is your operating manual for this project.

`docs/work/` holds planning docs, which are scaffolding. Never search it, and don't rely on search results from it. Open an entry only by its path: the open task you are working on, or a closed one for history, never as current behavior.
